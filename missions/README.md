# Game-owned mission contracts

`reactivo_13.slice.json` is a **proposed** mission design (not a working Godot map). It is validated using the version-pinned ARCONT `tools/vertical_slice_contract.py` workflow.

This folder stores *game-specific mission data*. The engine-neutral schema and validator are owned by ARCONT; gameplay code, scenes and Android APKs remain in this repository. Do not claim a CI design PASS demonstrates a playable level. See [GDD](../docs/production/REACTIVO_13_GDD.md).
