# FISURA — prototipo 3D

Proyecto de videojuego independiente en Godot. Primer objetivo: prototipo jugable de acción/extracción para probar, con evidencia, la utilidad de ARCONT. Los mapas usan su contrato semántico; ARCONT conserva el conocimiento, el juego conserva su código.
